# Installation

## Prerequisites
- Rust 1.70+
- Node.js 18+
- pnpm 8+

## From Source (Monorepo)
```bash
# Clone and install
git clone https://github.com/atomo-org/atomo.git
cd atomo
pnpm install

# Build Rust workspace
cargo build --workspace
```

Next: see Quick Start at `/guide/getting-started`.
